# Проверяемые примеры

Этот модуль содержит самодостаточные варианты ключевых фрагментов из книги.
Неполные иллюстрации остаются в тексте глав, а код здесь компилируется и проверяется.

| Пакет | Связанные темы |
|---|---|
| `algorithms` | Дейкстра, топологическая сортировка, DSU |
| `network` | границы сообщений в потоке TCP, ограничение размера |
| `language` | типы, переполнение, срезы, мапы, интерфейсы, каналы, контекст, обобщения |
| `concurrency` | отменяемый конвейер, ограничение конкурентности и передача причины ошибки |
| `httpserver` | предел тела, ошибки JSON, тест обработчика |
| `database` | белые списки динамических идентификаторов SQL |
| `logging` | устойчивая схема JSON-журнала |
| `architecture` | транзакционная граница сценария и перевод ошибок |
| `runtimeinfo` | размер, выравнивание и смещения полей |

Проверка всего модуля:

```bash
go test ./...
go vet ./...
go test -race ./...
```
