# Участие в проекте

Спасибо за исправление или дополнение Goracle. Проект рассчитан прежде всего на
стажёров и младших Go-разработчиков, поэтому точность базовой модели важнее объёма.

## Перед изменением

1. Проверьте, нет ли уже объяснения в соседней главе или справочном приложении.
2. Для нового факта найдите первичный источник.
3. Для полного примера подготовьте проверяемую версию в `examples`.
4. Не меняйте существующие изображения: их замена ведётся отдельно.

Редакционные правила описаны в
[`docs/project/content-standard.md`](docs/project/content-standard.md), а порядок
проверки — в [`docs/project/review-checklist.md`](docs/project/review-checklist.md).

## Локальная проверка

```bash
python scripts/check_docs.py
python scripts/check_language.py
python scripts/check_coverage.py
mkdocs build --strict
cd examples
go test ./...
go vet ./...
go test -race ./...
```

Изменение должно быть небольшим и цельным. В описании укажите, какую проблему
читателя оно решает, какие источники использованы и какие команды выполнены.

Быстрые проверки документации и примеров выполняются для каждого изменения.
Сетевой обход внешних ссылок запускается по понедельникам и вручную через
`Периодическая проверка`: временный сетевой сбой не должен блокировать локальную
работу, но исчезнувшая страница требует замены или удаления ссылки.
