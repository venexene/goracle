# Словарь

Словарь закрепляет термины, встречающиеся в нескольких разделах. Английский
вариант указан только для поиска документации и общения с инструментами.

| Термин | Значение |
|---|---|
| Анализ времени жизни (escape analysis) | Решение компилятора о размещении значения и допустимом времени его существования. |
| Атомарная операция | Неделимая для наблюдателей операция над общей памятью с определёнными гарантиями порядка. |
| Бюджет ошибок (error budget) | Допустимая доля неуспешных запросов или недоступности, следующая из SLO. |
| Взаимная блокировка (deadlock) | Состояние, в котором участники бесконечно ждут друг друга. |
| Встраивание функции (inlining) | Подстановка тела вызываемой функции в место вызова компилятором. |
| Горутина | Легковесная единица конкурентного выполнения, планируемая средой выполнения Go. |
| Дедлайн | Момент времени, после которого операцию следует отменить или считать просроченной. |
| Договор API | Наблюдаемое поведение, на которое вправе рассчитывать вызывающий код. |
| Идемпотентность | Свойство операции давать тот же наблюдаемый результат при безопасном повторе. |
| Интерфейс | Набор методов, описывающий требуемое поведение значения. |
| Конкурентность | Организация нескольких независимо продвигающихся работ. |
| Контекст | Значение `context.Context` для отмены, дедлайна и данных области запроса. |
| Мьютекс | Примитив взаимного исключения для защиты общего изменяемого состояния. |
| Наблюдаемость (observability) | Возможность судить о внутреннем состоянии системы по журналам, метрикам и трассировкам. |
| Обратное давление (backpressure) | Ограничение производителя скоростью потребителя или доступной ёмкостью. |
| Обобщённый код (generics) | Код с параметрами типов и явно заданными ограничениями. |
| Паника | Механизм аварийного прекращения обычного потока выполнения текущей горутины. |
| Параллелизм | Одновременное физическое выполнение вычислений. |
| Повтор (retry) | Новый запуск неуспешной операции с ограничением числа попыток и задержкой. |
| Пул соединений | Управляемый набор переиспользуемых соединений к внешней системе. |
| Сборка мусора | Автоматическое обнаружение недостижимой памяти и подготовка её к повторному использованию. |
| Связность | Степень зависимости одного модуля от знаний о другом модуле. |
| Состояние гонки | Ошибка, при которой результат зависит от неконтролируемого порядка событий. |
| Трассировка | Связанная запись участков выполнения одного распределённого запроса. |
| Участок трассировки (span) | Измеряемая операция внутри трассировки с началом, окончанием и атрибутами. |
| Шаблон | Повторяемый способ решения класса задач, а не обязательная заготовка кода. |
