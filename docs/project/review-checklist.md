# Лист рецензирования

Лист применяется к новой главе и к существенной редакции существующей. Пункт
можно отметить неприменимым, но нельзя считать проверенным без просмотра.

## Учебная ценность

- [ ] Названы необходимые предварительные знания.
- [ ] Результат сформулирован как действие читателя, а не как обещание «понять».
- [ ] Обязательный минимум отделён от углубления.
- [ ] Новый термин определён до первого использования.
- [ ] Есть корректный пример, характерная ошибка и способ самопроверки.
- [ ] Итог не пересказывает оглавление и ведёт к следующей теме.

## Техническая проверка

- [ ] Код отформатирован и компилируется либо явно обозначен как фрагмент.
- [ ] Полные примеры связаны с проверкой в `examples/coverage.json`.
- [ ] Утверждения о производительности подтверждены измерением.
- [ ] Гарантия языка не смешана с текущим устройством реализации.
- [ ] Для изменяемой реализации названа версия Go или зависимости.
- [ ] Ошибки, отмена, завершение работы и ограничения ресурсов рассмотрены там,
      где они относятся к теме.

## Редактура и источники

- [ ] Нет лишних английских слов, рекламных обещаний и повторов.
- [ ] Термины согласованы со словарём.
- [ ] Ссылки ведут на первичные источники; изменяемый исходный код закреплён.
- [ ] Заголовки уникальны внутри страницы, а текст ссылки понятен сам по себе.
- [ ] Новая страница включена в меню и учебный маршрут.

## Авторская проверка

- [ ] Автор может объяснить каждое техническое утверждение своими словами.
- [ ] Заимствованный материал отмечен ссылкой и не выдаётся за собственный.
- [ ] Автоматически предложенная формулировка проверена по коду или источнику.
- [ ] Известные ограничения записаны явно, а не скрыты ради завершённости текста.
