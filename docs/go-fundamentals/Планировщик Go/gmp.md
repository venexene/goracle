# Модель GMP

> **Проверено:** Go 1.27 · **Уровень:** младший разработчик — углублённый

G представляет горутину, M — поток операционной системы, P — право и ресурсы для
выполнения кода Go. Число P ограничено `GOMAXPROCS`; это предел одновременного
исполнения Go-кода, а не предел числа горутин или потоков.

Локальные очереди уменьшают общую конкуренцию, кража работы выравнивает нагрузку,
сетевой опросчик пробуждает готовые операции. Безопасные точки и асинхронное вытеснение
позволяют длинному вычислению уступить выполнение, но код всё равно должен иметь
отмену и разумную гранулярность работы.
