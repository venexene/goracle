# Работа с `database/sql`

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

`sql.DB` — безопасный для конкурентного доступа пул, а не одно соединение. Создайте его
один раз, проверьте `PingContext`, настройте число открытых и простаивающих соединений
и их срок жизни по пределам базы и числу экземпляров службы.

Используйте `QueryRowContext` для одной строки, `QueryContext` — для набора, всегда
закрывайте `Rows` и после цикла проверяйте `Rows.Err`. `ExecContext` подходит для
команд без набора строк. Подготовленное выражение имеет срок жизни и должно закрываться.

Транзакцию начинайте через `BeginTx`, откладывайте `Rollback` как безопасную страховку
и фиксируйте только после всех успешных операций. Внутри используйте только `tx`, а не
исходный `db`.

Подробнее: [пакет `database/sql`](reference.md#6-databasesql) и
[транзакции](reference.md#9-go).
