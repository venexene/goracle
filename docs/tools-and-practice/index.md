# Инструменты и практика

Инструменты, библиотеки и практики для прикладного Go: тестирование, базы данных и журналирование. Непрерывная интеграция, профилирование и безопасность пока рассматриваются внутри соответствующих глав, а не как отдельные темы.

Этот раздел — не о самом языке Go, а о том, как применять его в реальных проектах.

---

## Темы раздела

| Тема | О чём |
|---|---|
| [Тестирование](Тестирование%20в%20Go/testing.md) | `go test`, табличные тесты, тесты производительности, фаззинг, тестовые реализации, `httptest` и контейнеры |
| [Базы данных в Go](Базы%20данных%20в%20Go/db.md) | SQL-основы, ACID, `database/sql`, `sqlx`, `pgx`, миграции, ORM, `sqlc`, репозитории |
| [Журналирование](Логирование%20в%20Go/logging.md) | `log/slog`, уровни, атрибуты, обработчики, контекст и OpenTelemetry |

---

## Рекомендуемый порядок

1. **Тестирование** — научиться писать тесты на Go без внешних библиотек
2. **Базы данных в Go** — работать с БД через `database/sql`, `sqlx`, `pgx`
3. **Логирование** — освоить `log/slog`: структурированные логи, уровни, контекст
