# Инструменты и практика

Инструменты, библиотеки и практики, без которых не обходится ни один production-проект на Go: тестирование, базы данных, логирование, CI/CD, безопасность и многое другое.

Этот раздел — не о самом языке Go, а о том, как применять его в реальных проектах.

---

## Темы раздела

| Тема | О чём |
|---|---|
| [Тестирование](Тестирование%20в%20Go/testing.md) | `go test`, табличные тесты, бенчмарки, фаззинг, мокирование, `httptest`, testcontainers |
| [Базы данных в Go](Базы%20данных%20в%20Go/db.md) | SQL-основы, ACID, `database/sql`, `sqlx`, `pgx`, миграции, ORM, `sqlc`, репозитории |
| [Логирование](Логирование%20в%20Go/logging.md) | `log/slog`, уровни, атрибуты, handlers, контекстное логирование, OpenTelemetry |

---

## Рекомендуемый порядок

1. **Тестирование** — научиться писать тесты на Go без внешних библиотек
2. **Базы данных в Go** — работать с БД через `database/sql`, `sqlx`, `pgx`
3. **Логирование** — освоить `log/slog`: структурированные логи, уровни, контекст
