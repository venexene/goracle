# Атомарные операции и модель памяти

> **Проверено:** Go 1.27 · **Уровень:** младший разработчик

Гонка данных возникает при конкурентном доступе к одной области памяти, когда хотя бы
один доступ — запись и нет требуемой синхронизации. Отношение «происходит до» создают,
в частности, блокировки, каналы и документированные атомарные операции.

Предпочитайте типизированные `atomic.Bool`, `atomic.Int64`, `atomic.Uint64` и
`atomic.Pointer[T]`. Атомарность одного поля не делает атомарным инвариант нескольких
полей. Для связанного состояния обычно понятнее мьютекс или неизменяемый снимок,
публикуемый через `atomic.Pointer`.

Подробнее: [полный справочник](reference.md).
