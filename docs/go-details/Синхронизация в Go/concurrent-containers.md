# Конкурентные контейнеры

> **Проверено:** Go 1.27 · **Уровень:** младший разработчик

Обычная мапа не поддерживает конкурентную запись. Часто достаточно `map` под
`sync.RWMutex`: типы ключа и значения остаются явными, а составные операции выполняются
под одной блокировкой. `sync.Map` полезна для некоторых схем с редкой записью или
непересекающимися ключами, но выбор нужно подтверждать профилем.

`sync.Pool` — временный кеш переиспользуемых объектов, содержимое которого среда
выполнения может удалить в любой сборке мусора. Он не подходит для хранения состояния,
ограничения числа объектов или обязательного освобождения ресурсов.
