# Координация горутин

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

`sync.WaitGroup` ждёт конечную группу работ, `sync.Once` публикует однократный результат,
`sync.Cond` позволяет ждать изменения условия под блокировкой. Проверяйте условие
`Cond` в цикле: пробуждение означает лишь необходимость проверить состояние снова.

В Go 1.25+ `WaitGroup.Go` объединяет запуск и учёт горутины, но не передаёт ошибки и не
отменяет соседей. Для дерева отменяемых операций подходят контекст и группа, которая
возвращает первую ошибку.
