# Блокировки

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

`sync.Mutex` защищает инвариант, а не отдельную строку. Укажите рядом, какие поля он
защищает, держите критическую секцию короткой и не выполняйте под блокировкой сетевой
вызов без необходимости. Копировать использованный мьютекс нельзя.

`sync.RWMutex` полезен не по правилу «чтений больше», а после замера: конкуренция,
длительность чтений и цена внутренней координации важнее простого количества.
Устанавливайте единый порядок нескольких блокировок, чтобы избежать взаимного ожидания.

Подробнее: [полный справочник](reference.md).
