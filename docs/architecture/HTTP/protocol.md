# Протокол HTTP

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

HTTP — протокол запросов и ответов. Метод и цель описывают намерение, заголовки —
метаданные, тело — необязательное представление данных. Код ответа относится ко всей
операции: `2xx` сообщает об успехе, `3xx` — о перенаправлении, `4xx` — о проблеме
запроса клиента, `5xx` — о неспособности сервера выполнить корректный запрос.

Безопасность метода означает отсутствие ожидаемого изменения состояния, а
идемпотентность — одинаковый итог одной и нескольких одинаковых операций. Это не
гарантирует отсутствие записей журнала и не разрешает автоматически повторять любой
`POST`.

HTTP/1.1 упорядочивает сообщения в соединении, HTTP/2 мультиплексирует потоки, HTTP/3
использует QUIC. Прикладная семантика методов и кодов сохраняется, но правила кадров и
управления потоком различаются.

Продолжение: [введение в протокол](reference.md#http-introduction) и
[устройство HTTP/1.1](reference.md#http11).
