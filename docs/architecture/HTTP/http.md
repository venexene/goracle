# HTTP в Go: учебный маршрут

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик
> Прежний адрес главы сохранён; подробный материал перенесён в отдельный справочник.

HTTP объединяет несколько разных задач. Изучайте их по порядку:

1. [Протокол HTTP](protocol.md) — сообщения, методы, коды, заголовки, версии и кеширование.
2. [Сервер `net/http`](server.md) — маршруты, обработчики, сроки, ограничения и завершение.
3. [Клиент и транспорт](client.md) — повторное использование соединений, сроки и повторы.
4. [Безопасность и эксплуатация](security-and-operations.md) — доверие к прокси, пределы, телеметрия и тесты.
5. [Полный справочник](reference.md) — подробности протокола, внутреннее устройство и дополнительные возможности.

Для первой рабочей службы достаточно уметь задать маршруты, проверить входные данные,
ограничить тело и заголовки, распространить контекст, корректно завершить сервер и
проверить обработчики через `httptest`. Внутреннее устройство транспорта изучайте
после того, как открытый договор `net/http` стал понятен.
