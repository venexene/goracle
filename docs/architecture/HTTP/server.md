# Сервер `net/http`

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

Соберите `http.Server` явно: задайте обработчик, `ReadHeaderTimeout`, `WriteTimeout`,
`IdleTimeout`, `MaxHeaderBytes` и принимаемые `Protocols`. Ограничивайте тело через
`http.MaxBytesReader` до декодирования. Маршрутизация не заменяет проверку данных и
авторизацию.

Обработчик получает контекст запроса и передаёт его операциям ввода-вывода. При
остановке сначала прекратите принимать новые соединения, затем вызовите `Shutdown` с
конечным сроком; после неуспеха допустим аварийный `Close`.

Проверяйте функции через `httptest.NewRequest` и `ResponseRecorder`, а работу реального
соединения — через `httptest.NewServer`. Конкурентный доступ к общему состоянию должен
проходить под тестом с детектором гонок.

Продолжение: [обзор `net/http`](reference.md#net-http-overview) и
[маршрутизация `ServeMux`](reference.md#serve-mux).
