# Клиент HTTP и транспорт

> **Проверено:** Go 1.27 · **Уровень:** стажёр — младший разработчик

Повторно используйте один настроенный `http.Client`: он безопасен для конкурентного
доступа, а его транспорт хранит пул соединений. Задавайте общий срок клиента либо срок
контекста каждой операции. После получения ответа читайте или закрывайте `Body`, иначе
соединение может не вернуться в пул.

Повтор допустим для временной ошибки и идемпотентной операции либо при наличии ключа
идемпотентности. Ограничьте число попыток и общий бюджет, добавьте случайное смещение
задержки и учитывайте `Retry-After`.

Перенаправления и файлы cookie относятся к политике `http.Client`; параметры сокетов,
прокси и пула — к `http.Transport`.

Продолжение: [клиент и `Transport`](reference.md#12-http-transport) и
[конкурентность сервера](reference.md#13).
