# Безопасность и эксплуатация HTTP

> **Проверено:** Go 1.27 · **Уровень:** младший разработчик

Принимайте `Forwarded` и `X-Forwarded-For` только от доверенных прокси. Ограничивайте
размеры заголовков и тела, сроки, число одновременных операций и глубину собственных
очередей. Неодинаковый разбор `Content-Length` и `Transfer-Encoding` на соседних узлах
может позволить подменить границы запросов.

Телеметрия должна содержать метод, шаблон маршрута, код, длительность, размер и
идентификатор трассировки. Сырой путь, пользователь и текст ошибки создают неограниченное
число значений метрик. Секреты и персональные данные нельзя записывать в журнал.

Модель угроз также включает TLS, CSRF для браузерных клиентов, межсайтовые запросы,
проверку имени узла при исходящих запросах и защиту от обращения к внутренним адресам.
