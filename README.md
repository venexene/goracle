Русскоязычная база знаний о Go: от основ языка до устройства среды выполнения
и архитектуры приложений. В проекте 32 тематические главы в пяти разделах,
диаграммы, примеры кода и полнотекстовый поиск.

Основная аудитория — стажёры и младшие Go-разработчики. В каждой главе важно
отделять устойчивый контракт языка и открытого API от деталей реализации,
зависящих от версии. Текущая базовая версия — **Go 1.27**.

**Сайт:** [venexene.github.io/goracle](https://venexene.github.io/goracle)

```text

├── requirements.txt            # закреплённые версии зависимостей

├── docs/
│   ├── index.md                # главная страница и карта тем
```

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
mkdocs serve
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000`.

Строгая проверка сборки:

```bash
mkdocs build --strict
```

Проверка документации и примеров:

```bash
python scripts/check_docs.py
python scripts/check_language.py
cd examples
go test ./...
go vet ./...
go test -race ./...
```

Результат записывается в каталог `site/`.

## Требования к содержанию

Материал строится по трём уровням:

1. **Нужно знать** — устойчивый минимум для стажёра.
2. **Полезно на практике** — приёмы, применяемые младшим разработчиком в рабочем коде.
3. **Как устроено внутри** — необязательные детали среды выполнения и компилятора,
   которые могут меняться между выпусками Go.

Полная программа, приведённая как готовый пример, должна компилироваться на Go
1.27. Утверждения о компиляторе и среде выполнения должны указывать проверенную
версию и ссылаться на официальную документацию или исходный код соответствующего
тега.

Результаты редакционной проверки и журнал изменений ведутся в рабочем файле
`CONTENT_AUDIT.md`, расположенном рядом с каталогом репозитория.
